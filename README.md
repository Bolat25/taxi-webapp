# taxi-webapp

Мини-приложение Telegram для выбора точек поездки на карте: откуда (А) и куда (Б).

- Карта: [Leaflet](https://leafletjs.com) + тайлы OpenStreetMap.
- Поиск адресов и подпись точки: [Nominatim](https://nominatim.org) (не чаще 1 запроса в секунду, поиск по кнопке).
- Точки передаются боту через `Telegram.WebApp.sendData`, поэтому приложение открывается только
  reply-кнопкой бота «🗺 Выбрать на карте».

Параметры URL (их подставляет бот):

| Параметр | Значение |
|---|---|
| `mode` | `both` — выбрать А и Б, `to` — только Б |
| `lat`, `lon` | центр карты (центр города пассажира) |
| `z` | начальный масштаб |

Данные, которые получает бот:

```json
{"v": 1, "a": {"lat": 43.2641, "lon": 76.9286, "label": "ТРК Mega Park"},
         "b": {"lat": 43.2398, "lon": 76.9133, "label": "проспект Абая, 52"}}
```

Открытая вне Telegram страница ничего не отправляет и показывает эти данные внизу — так удобно проверять.
